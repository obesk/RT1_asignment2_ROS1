Action client node

This is an action client node to allows the user to interact with the goals. Specifically the user can:

  • Update the goal

  • Get status of the current goal retrieving mission

This node also publishes a custom message with the current robot velocity and position

Module author: Roberto Bertelli <s7289118@studenti.unige.it>
